## 1. 快速开始

### 1.1 打开平台

在浏览器地址栏输入平台网址（管理员会提供，例如 `http://192.168.1.10:5173`），进入主界面。

界面分为三大区域：

| 区域 | 作用 |
| --- | --- |
| **左侧导航栏** | 切换"任务管理 / 新建任务 / 成果库 / 对比定损 / UXO 探测"等模块 |
| **顶部状态栏** | 实时显示后端处理节点是否健康（绿点 = 正常） |
| **主操作区** | 当前模块的功能页面 |

> 💡 **小贴士**：右上角有"🤖 AI 助手"按钮，点击可咨询任何使用问题。

### 1.2 第一次使用先做这一件事

- 进入 **任务管理** 页，确认左上角"处理节点"显示 **绿色**。
- 如果是 **红色**：请联系平台管理员，处理服务可能未启动。
- 如果是 **黄色**：服务正在初始化，请等待 30 秒后刷新页面。

### 1.3 你能用什么浏览器

- ✅ Chrome 90+、Edge 90+、Firefox 88+、Safari 14+
- ❌ IE 浏览器不支持

## 2. 任务管理

> 把无人机拍到的影像变成"地图"和"三维模型"的过程。这一节是平台最常用的功能。

### 2.1 新建一个影像处理任务

**预计耗时**：上传 5 分钟（取决于影像大小）+ 后台处理 20~60 分钟。

1. 左侧导航点 **"新建任务"**
2. 任务名称：取一个容易记的名字，例如 `重庆綦江-20250812-灾后`
3. **拖拽影像到上传区**（或将文件选入）：
   - 支持 `.jpg` / `.jpeg` 格式
   - 一次建议 30~200 张，单张不超过 20 MB
   - 文件名建议带拍摄时间，例如 `DJI_20250812_143022.jpg`
4. **坐标系**：默认 `自动` 即可。**有 GCP/RTK 控制点**时选对应的 UTM 区
5. **生成选项**（一般保持默认）：
   - DSM（地表高程模型）：✅ 推荐开
   - DEM（地面高程模型）：✅ 推荐开
   - DTM（地形模型）：仅在已有精细地形数据时勾选
6. 点 **"提交任务"** 按钮

> ⚠️ **注意**：不要关浏览器！处理在后台运行，关浏览器不影响。但若重启电脑会中断上传。

### 2.2 跟踪任务进度

1. 进入 **任务管理** 页，找到你刚提交的任务
2. 状态会从 `排队中` → `处理中` → `已完成` 变化
3. 点任务名称进入 **详情页**：
   - **进度条**：显示当前阶段（特征提取 → 稀疏匹配 → 稠密重建 → 模型生成）
   - **日志区**：实时显示处理引擎输出（看不懂没关系，主要看是否报错）

> 💡 **小贴士**：处理时间与影像数量、分辨率、是否开启 DSM/DEM 正相关。100 张图大概需要 20~40 分钟。

### 2.3 任务完成后导出规范成果

1. 在 **任务详情页**，状态变成 `已完成` 后
2. 点 **"导出规范成果"** 按钮
3. 系统会把以下文件落到成果库（每个任务一个目录 `task_XXX/`）：

| 文件 | 说明 | 用途 |
| --- | --- | --- |
| `orthophoto.tif` | 正射影像 | 平面图、地图底图 |
| `dsm.tif` | 数字表面模型 | 含建筑物、植被的"毛坯"地形 |
| `dem.tif` | 数字高程模型 | 去掉建筑物、植被的"真"地形 |
| `point_cloud.laz` | 密集点云 | 三维量测、对比分析 |
| `model/` | 三维模型目录 | 带纹理的三维可视化 |
| `metadata.xml` | 元数据 | 处理参数、坐标系、拍摄时间 |

> ✅ **导出后即可进入"对比定损"环节**。

### 2.4 重试 / 删除任务

- **重试**：处理失败的任务，点 `重试` 按钮，系统会用同样参数重新跑
- **删除**：点 `删除` 按钮会同时清理处理引擎中的数据和已导出成果（不可恢复！）

## 3. 对比定损

> 灾前/灾后两个时间点的成果做"差值分析"，量化"哪里变了、变了多少"。核心是 **DSM/DEM/DTM 之间的差值图**。

### 3.1 什么时候用

- ✅ 滑坡前后的土方量计算
- ✅ 房屋倒塌/新建前后变化检测
- ✅ 道路、水渠、地形等任何地表变化的量化

### 3.2 操作步骤

**预计耗时**：3~5 分钟提交，10~20 分钟后台处理。

1. 进入 **对比定损** 页
2. **灾前任务**：下拉选一个已完成的任务（一般是较早拍摄的）
3. **灾后任务**：下拉选一个已完成的任务（一般是较晚拍摄的）
4. **高程资产**：默认 `DSM`，精确量化地表变化选 `DEM`（已滤除建筑物/植被）
5. **变化阈值**：默认 `2.0 米`——只有高程差超过这个值的区域才会被标记为"显著变化"
6. **垂直配准**：✅ **强烈建议开启**。不同时期的重建会有整体"上下漂移"，开启后系统会自动扣除这层系统差，让结果只反映"真变化"
7. 点 **"开始对比"** 按钮

### 3.3 看懂对比结果

完成后会自动跳转到结果页，包含三大模块：

#### 🎚 卷帘对比（左上）

- 中间一根竖线，左边显示灾前影像、右边显示灾后影像
- 拖动竖线可逐像素对比
- 切换"灾前/灾后/差值"三选一叠加显示

#### 🗺 差值图渲染（右上）

- 红色 = **地表抬升**（如新建建筑、堆积土方）
- 蓝色 = **地表沉降**（如滑坡、塌陷）
- 灰白色 = 基本无变化
- 颜色越深，变化越剧烈

#### 📊 6 张统计卡片（底部）

| 卡片 | 含义 |
| --- | --- |
| **变化面积** | 高程差超过阈值的总面积（平方米） |
| **平均变化** | 显著变化区域的平均高程差（米） |
| **最大抬升** | 抬升最高点的高度（米） |
| **最大沉降** | 沉降最深点的深度（米） |
| **抬升体积** | 所有抬升区域 × 厚度 = 体积（立方米） |
| **沉降体积** | 所有沉降区域 × 厚度 = 体积（立方米） |

> 💡 **小贴士**：差值图与统计是基于 **自动配准 + 阈值判定** 的，结果用于辅助决策。最终定损报告应结合人工现场核查。

### 3.4 历史对比任务

页面下方有"历史对比"列表，点任意一行可重新查看历史结果。系统保留所有对比记录，**不会自动删除**。

## 4. UXO 三源探测

> 未爆物（Unexploded Ordnance，简称 UXO）智能识别。融合 **磁法 + 探地雷达 + 电磁感应** 三种地球物理探测手段，给出"疑似未爆物"的位置和风险等级。

### 4.1 三种探测源是什么

| 源 | 英文 | 原理 | 适合场景 |
| --- | --- | --- | --- |
| **磁法** | Magnetometry | 测量地磁异常，铁质物体会产生强磁信号 | 大型铁壳炸弹、炮弹 |
| **探地雷达** | GPR (Ground Penetrating Radar) | 发射电磁波看地下反射 | 任何金属/非金属目标，可分层 |
| **电磁感应** | EMI (Electromagnetic Induction) | 发射一次磁场，激发金属二次场 | 浅层小目标，灵敏度高 |

> 💡 **小贴士**：单一手段误报率高（磁法会被铁栅栏误报、GPR 会被管道误报）。**三源融合**才能稳定判级。

### 4.2 上传探测数据

1. 进入 **UXO 探测** 页
2. 选择数据来源（磁法 / GPR / EMI 中的 1~3 种）
3. 上传数据文件（支持的格式见页面提示）
4. 选填 **日变改正文件**（磁法强烈建议上传，否则会被地磁日变化干扰）
5. 点 **"开始融合分析"**

**预计耗时**：3~5 分钟提交，5~15 分钟后台处理（取决于数据量）。

### 4.3 看懂判级结果

完成后页面会显示：

- **地图视图**：彩色点位 = 疑似未爆物，颜色深浅代表置信度
- **判级清单**：表格列出每个目标的 ID、坐标、深度、风险等级（高/中/低）

> ⚠️ **注意**：所有判级为"高风险"的目标都应安排专业人员现场核查，**不可直接开挖**。系统只是辅助决策。

### 4.4 工具页

左侧导航点 **"UXO 工具"** 进入辅助模块：

| 工具 | 用途 |
| --- | --- |
| **元数据管理** | 录入/编辑探测项目的基础信息（项目名、测区、负责人） |
| **日变改正** | 上传基准站数据做地磁日变化校正 |
| **航线规划** | 输入测区高程，输出"蛇形恒高"飞行航线（CSV / KML） |
| **质控看板** | 查看每个项目的覆盖率、噪声水平、是否需要重飞 |

## 5. 成果库

> 所有已导出成果的"仓库"。支持打包下载、批量清理。

### 5.1 查看成果列表

进入 **成果库** 页，按目录展示每个任务。展开后可看到该任务下所有文件。

### 5.2 打包下载

1. 找到你要下载的任务目录
2. 点 **"打包下载"** 按钮
3. 系统会生成一个 `.zip` 文件，包含整个 `task_XXX/` 目录

### 5.3 清理超期成果

- 平台默认 **保留 30 天** 的导出成果
- 管理员可手动点 **"清理超期"** 按钮一次性删除

> ⚠️ **注意**：清理操作不可恢复。下载并归档后再清理。

## 6. 常见问题

### Q1: 上传后没反应 / 上传失败？

排查步骤：

1. 检查文件格式：必须 `.jpg` / `.jpeg`（部分老相机 `.JPG` 大写也支持）
2. 单张超过 20 MB？先用图像处理软件压一下
3. 浏览器是否拦截了弹窗？换个浏览器试试
4. 还是不行 → 截图发给管理员

### Q2: 任务一直"排队中"？

处理节点可能在忙（同时跑多个任务），请耐心等待。如果排队超过 30 分钟仍未启动，联系管理员检查处理服务。

### Q3: 任务失败 / 进度卡住？

1. 进入 **任务详情页** 看日志尾部
2. 常见原因：
   - 影像质量差（模糊、过曝、过暗）→ 重新拍摄
   - 影像重叠度不足（< 60%）→ 重新规划航线
   - GPS 精度差 → 添加 GCP 控制点
3. 点 **"重试"** 按钮重跑

### Q4: 对比结果看着不合理？

可能原因：
- **两期任务用了不同参数**（如一个开了 DSM、一个没开）→ 重新提交同参数任务
- **没有配 GCP/RTK** → 重建本身就有米级地理偏差，对比前必须先做"垂直配准"
- **阈值设置不当** → 把阈值从 2.0 米调到 0.5 米试试

### Q5: 差值图全是红色/蓝色？

说明两期任务参数严重不一致，**不要相信结果**。请：
1. 确认两个任务都勾选了一样的"生成选项"
2. 确认坐标系选择一致
3. 重新跑一次两期任务

### Q6: AI 助手说"我不清楚"？

知识库只覆盖本手册和需求文档里的内容。涉及：
- 项目专属数据
- 未在手册列出的高级功能
- 客户具体业务问题

这些问题 AI 助手答不了，请联系管理员。

### Q7: 想离线用（没网络）？

平台需要内网部署（处理节点需要 GPU 算力）。请联系管理员部署本地服务器版本。

### Q8: 浏览器显示"网络错误"？

- 检查后端处理节点是否健康（顶部状态栏）
- 检查浏览器控制台（F12）错误信息
- 截图发给管理员
